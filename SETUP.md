## Install

Copy these files into the root of your `mohamed-kaif-1` profile repository.

Then:

```bash
git add .
git commit -m "redesign profile readme"
git push origin main
```

## Enable the contribution animation

The README already points to the `output` branch generated by the workflow.

In GitHub:

1. Open the profile repository.
2. Go to **Settings → Actions → General**.
3. Under **Workflow permissions**, allow **Read and write permissions** if your repository policy requires it.
4. Open **Actions → generate contribution animation**.
5. Run the workflow manually once.

After the first successful run, the workflow creates/updates the `output` branch and the snake appears in the README.

## Why this design

- The hero is a custom SVG stored in your own repository — no generic typing-banner dependency.
- Motion is concentrated in one strong visual instead of making every section move.
- The first screen explains what you build.
- Projects show technical proof before skill logos.
- The contribution snake is generated by GitHub Actions and supports GitHub light/dark mode.
- The profile avoids inflated metrics and generic "passionate developer" copy.

## Easy customizations

Edit `assets/kaif-core.svg` to change:
- hero title
- accent colors
- rotating focus labels
- status text

Edit `README.md` to change:
- current experiments
- selected builds
- awards
- links

If you add LinkedIn later, place it beside the Portfolio and Email buttons at the top.
